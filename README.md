# Cantinho dos Gigantes

Sistema de pedidos com Node.js, Express e SQLite.

## Rodar
1. Instale Node.js.
2. No terminal desta pasta: `npm install`
3. Depois: `npm start`
4. Abra `http://localhost:3000`

Senha inicial do Admin: `1234`.

## Render
Crie um Web Service conectado ao GitHub.
Build Command: `npm install`
Start Command: `npm start`

Para preservar o banco SQLite na hospedagem, use armazenamento persistente e defina `DB_PATH` para o caminho do disco persistente.

O sistema cria automaticamente `cantinho.db`.
